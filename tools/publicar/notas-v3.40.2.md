## v3.40.2 — Modo servidor sem bloqueio do antivírus · Salgueiro Terminal 1.0.1

### 🛡️ Antivírus
Ao ligar o modo servidor, o Windows Defender de uma loja barrou a criação do vigia, a tarefa que reabre o sistema se ele fechar sozinho. Agora o vigia é registrado de outro jeito, sem o comando que o antivírus estranhava. Quem já estava em modo servidor recebe o ajuste sozinho ao atualizar.

### 🖥️ Salgueiro Terminal 1.0.1 (vai junto; os caixas se atualizam sozinhos pela rede da loja)
- **Imprime sem a janela do Windows desde o primeiro uso**: na primeira vez o caixa escolhe sozinho a térmica para o cupom, a de etiquetas e a padrão do Windows para folhas (dá para trocar no ⚙).
- Botão **Atualizar agora** no ⚙ do caixa: busca a versão nova na internet e no computador do escritório.
- Se o endereço do computador do escritório mudar, o caixa o encontra de novo pelo nome.
- A tela do sistema se ajusta sozinha a monitores menores, sem cortar.
- Depois de se atualizar, o programa reabre sozinho.

## v3.39.0 — Modo servidor · chave do pendrive

### 🖥️ Modo servidor

Em **Configurações → 🖥️ Servidor**, uma chave transforma o computador do escritório no servidor da loja:
- abre sozinho junto com o Windows, minimizado;
- reabre sozinho se fechar ou travar (conferido a cada minuto);
- o computador não entra em suspensão na tomada (ao desligar a chave, volta como era antes);
- o acesso em rede é ligado junto.

A tela confere cada item direto no Windows e mostra os caixas conectados agora.

### 🛑 Fechar o servidor pergunta antes

No servidor, o X avisa que fechar desliga todos os caixas. O botão padrão é **Deixar aberto**, que só minimiza. Fechando de propósito, o sistema espera 30 minutos antes de reabrir sozinho.

### 🔌 Chave do pendrive

A segunda cópia no pendrive (Configurações → 💾 Backup) agora é uma chave liga/desliga. Sem pendrive, deixe desligada.
